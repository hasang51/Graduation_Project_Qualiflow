# QualiFlow Frontend

React + Vite + TypeScript UI for:
- register/login,
- authenticated PDF upload,
- extraction result rendering,
- analysis history and reopen detail.

## Run

```bash
npm install
copy .env.example .env
npm run dev
```

Set API base URL:

```env
VITE_API_BASE_URL=http://127.0.0.1:8000
```
